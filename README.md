# Six Words, One Story

This program writes a complete six-word story to /output/entry.txt for the make.fun competition "Six Words, One Story". Run `python3 main.py`; the output directory comes from the MAKEFUN_OUTPUT_DIR environment variable when set, otherwise it defaults to /output.
